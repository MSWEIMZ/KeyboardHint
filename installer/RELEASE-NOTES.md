# 键盘小助手 v1.2.0

按住 **Ctrl / Alt / Win**，屏幕底部弹出当前应用的快捷键提示键盘——灵感来自华为 MateBook Fold 虚拟键盘，给实体键盘用户的同款体验。

## 下载哪个

| 文件 | 说明 |
|---|---|
| **KeyboardHint-Setup-1.2.0.exe** | 安装包（推荐）：安装到 `%LOCALAPPDATA%\Programs`，可选开机自启/桌面快捷方式，无需管理员权限 |
| **KeyboardHint.exe** | 便携版：单文件 69MB，双击即用，无需安装 .NET，放哪都能跑 |

首次启动会在托盘气泡提示使用方法；右键托盘图标可进设置、快捷键编辑器、换肤。

## 功能

- **111+ 应用、约 4800 条快捷键**：WPS/Office、JetBrains/VS/VS Code、Edge/Chrome/Firefox 等浏览器、Figma/MasterGo、Premiere/达芬奇/剪映、PotPlayer/VLC、TIM/微信/钉钉/飞书、Xshell/Tabby、Total Commander/Everything、PDF/远程桌面等
- **组合键层**：Ctrl / Ctrl+Shift / Ctrl+Alt / Alt+Shift / Shift / Win 系列——按住 Ctrl 再按 Shift 实时切层
- **快捷键编辑器**：选应用 → 选修饰层 → 表格里选按键填说明，可视化增删改，支持新建应用和导入 JSON
- **Win11 Fluent 界面**：自绘标题栏、圆角卡片、主题（深/浅）+ 8 种强调色
- **可靠兜底**：默认软件渲染，无 GPU/驱动异常/虚拟机/远程桌面都能用；选硬件渲染时启动自动探针，坏 GPU 自动回退
- **防误触**：短按、Ctrl+滚轮、Ctrl+点击不误弹；可排除指定进程
- 托盘菜单、开机自启、钉住模式、延迟/透明度可调、自定义快捷键（用户目录 JSON 覆盖内置）

## 系统要求

Windows 10 1809+ / Windows 11，x64。无需安装 .NET 运行时。
